## Convención

- Un ADR por decisión relevante.
- Nombre: `ADR-NNN-titulo-corto.md`.
- Estados: `Propuesto`, `Aceptado`, `Rechazado`, `Sustituido por ADR-NNN`.
- Una decisión aceptada no se reescribe: se sustituye con un nuevo ADR.
